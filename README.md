# 數字一定要從檔案算 Numbers From Files — Claude Skill

AI 回報的數字常常是記憶裡的、上一份抄來的，或分類講錯。這個 Skill 讓 AI 每個數字都當場從檔案算，附出處，算不出來就照實寫未確認。

## 怎麼用
- 每個數字當場由來源檔算（數、加總），不從記憶或上一份抄。
- 數字後面的說法（是什麼、哪一類、是不是最新）照來源檔的欄位與檔案時間。
- 每個數字附出處；算不出來寫「未確認」；交出前再算一次。

## 限制
- 還沒有實際使用紀錄。
- Skill 內容是繁體中文。
- 不保證一定有效；AI 不一定每次都照做。
